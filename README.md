# 📌 Project Overview

This project focuses on **protein function classification** using Machine Learning techniques.

The goal is to predict protein functions such as:
- Hemoglobin
- Kinase
- Enzyme-related proteins
- Other functional protein groups

The workflow includes:
1. Raw dataset preprocessing
2. Feature preparation
3. Machine Learning model training
4. Evaluation and visualization

The model was developed using **Python** and the **Scikit-Learn** ecosystem.
